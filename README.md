# 贝焙面包 · 公开产品菜单

暖色系翻页电子菜单，封面使用门店海报，品类数据来自产品表（甜品类 18 款、蛋糕类 53 款）。

## 本地预览

在项目目录执行：

```bash
npx --yes serve .
```

浏览器打开提示的地址即可。

## 发布到 GitHub Pages（公开链接）

1. 在 GitHub 创建仓库（或使用已有仓库），将本项目推送到 `main` 分支。
2. 仓库 **Settings → Pages → Build and deployment**：
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)**
3. 等待 1～3 分钟，访问：

`https://<你的用户名>.github.io/<仓库名>/`

任何人可通过该链接打开菜单。
